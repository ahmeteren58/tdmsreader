\section*{Problem Statement}

The two-dimensional Laplace equation around a cylinder is
\begin{equation}
\frac{1}{r}\frac{\partial}{\partial r}\left(r\frac{\partial u}{\partial r}\right)+\frac{1}{r^2}\frac{\partial^2 u}{\partial \theta^2}=0,
\label{eq:laplace}
\end{equation}
with domain $(\theta,r)\in[0,2\pi]\times[1,2]$. The analytical solution is
\[u(r,\theta)=\left(r-\frac{1}{r}\right)\sin\theta
\]
and the boundary conditions are
\[
u(1,\theta)=0,
\qquad
u(2,\theta)=\frac{3}{2}\sin\theta.
\]

The tasks are:
\begin{enumerate}
    \item solve the problem by a fully implicit second-order finite difference method on $81\times41$, $161\times81$, and $321\times161$ meshes,
    \item plot the error versus $\Delta r$ and $\Delta\theta$ in log-log scale and compute the convergence rate,
    \item find the solution inside the cylinder for $0\le r\le1$.
\end{enumerate}

\section*{Finite Difference Formulation}

Expanding Eq.~\eqref{eq:laplace},
\begin{equation}
\frac{\partial^2 u}{\partial r^2}+\frac{1}{r}\frac{\partial u}{\partial r}+\frac{1}{r^2}\frac{\partial^2 u}{\partial \theta^2}=0.
\label{eq:expanded}
\end{equation}

A uniform grid is used in both directions. Since the problem is periodic in $\theta$, I use $N_\theta$ distinct angular points and take
\[
\Delta\theta=\frac{2\pi}{N_\theta},
\qquad
\Delta r=\frac{1}{N_r-1}.
\]
The grid points are
\[
\theta_i=(i-1)\Delta\theta, \quad i=1,2,\dots,N_\theta,
\]
\[
r_j=1+(j-1)\Delta r, \quad j=1,2,\dots,N_r.
\]

At an interior point, second-order central differences give
\[
\frac{\partial^2 u}{\partial r^2}\bigg|_{i,j}\approx\frac{u_{i,j+1}-2u_{i,j}+u_{i,j-1}}{\Delta r^2},
\]
\[
\frac{1}{r_j}\frac{\partial u}{\partial r}\bigg|_{i,j}\approx\frac{u_{i,j+1}-u_{i,j-1}}{2r_j\Delta r},
\]
\[
\frac{1}{r_j^2}\frac{\partial^2 u}{\partial \theta^2}\bigg|_{i,j}\approx\frac{u_{i+1,j}-2u_{i,j}+u_{i-1,j}}{r_j^2\Delta\theta^2}.
\]

Substituting these into Eq.~\eqref{eq:expanded}, the discrete equation becomes
\begin{equation}
\begin{aligned}
&\left(\frac{1}{\Delta r^2}-\frac{1}{2r_j\Delta r}\right)u_{i,j-1}
+\left(-\frac{2}{\Delta r^2}-\frac{2}{r_j^2\Delta\theta^2}\right)u_{i,j} \\
&\qquad +\left(\frac{1}{\Delta r^2}+\frac{1}{2r_j\Delta r}\right)u_{i,j+1}
+\frac{1}{r_j^2\Delta\theta^2}(u_{i-1,j}+u_{i+1,j})=0.
\end{aligned}
\label{eq:fd}
\end{equation}

This gives a five-point stencil in $(r,\theta)$ space. The angular direction is periodic, so when $i=1$ or $i=N_\theta$, the neighboring point is wrapped to the other side. The inner boundary is $u(1,\theta)=0$, and the outer boundary is $u(2,\theta)=\frac{3}{2}\sin\theta$. These known boundary values are moved to the right-hand side during matrix assembly. The final linear system is sparse and is solved directly in MATLAB using the backslash operator.

\section*{Results and Discussion}

The error is computed from
\begin{equation}
E=\frac{\|u_{i,j}-u_{\text{analytical}}\|_2}{\sqrt{N_\theta N_r}}.
\label{eq:error}
\end{equation}

The convergence rate is computed between two consecutive meshes using
\begin{equation}
p = \frac{\log\left(E_{\text{coarse}}/E_{\text{fine}}\right)}{\log\left(h_{\text{coarse}}/h_{\text{fine}}\right)},
\label{eq:rate}
\end{equation}
where $h$ represents the grid spacing. In this problem, $h$ can be taken as $\Delta r$ or $\Delta\theta$. The error decreases by about a factor of $4$ as the grid is refined, which is consistent with second-order accuracy.

\section*{Interior Solution ($0\le r\le1$)}

For the region inside the cylinder, the governing equation is still Laplace's equation,
\[
\frac{1}{r}\frac{\partial}{\partial r}\left(r\frac{\partial u}{\partial r}\right)
+\frac{1}{r^2}\frac{\partial^2 u}{\partial \theta^2}=0,
\qquad 0\le r\le1,
\]
with boundary condition
\[u(1,\theta)=0.
\]

In the exterior problem the analytical solution was $u(r,\theta)=(r-1/r)\sin\theta$, which contains the term $r^{-1}$ and therefore blows up as $r\to 0$. So that form cannot be used inside the disk.

The general solution of Laplace's equation in polar coordinates that remains bounded at the origin is
\[u(r,\theta)=a_0+\sum_{n=1}^{\infty} r^n\left(a_n\cos n\theta+b_n\sin n\theta\right).
\]
The negative-power terms $r^{-n}$ are excluded here because they would make $u$ singular at $r=0$.

Applying the boundary condition $u(1,\theta)=0$ gives
\[
0=a_0+\sum_{n=1}^{\infty}\left(a_n\cos n\theta+b_n\sin n\theta\right).
\]
By the orthogonality of the Fourier basis, each coefficient must vanish individually:
\[
a_0=0,\qquad a_n=0,\qquad b_n=0,\qquad \text{for all } n\ge1.
\]
Therefore,
\[u(r,\theta)=0,\qquad 0\le r\le1.
\]

This is also consistent with the maximum principle for harmonic functions: since $u$ satisfies Laplace's equation inside the disk and equals zero on the entire boundary $r=1$, the maximum and minimum of $u$ must both be zero, so $u\equiv 0$ throughout the interior.

If one were to set up the same finite difference solver on the domain $0\le r\le1$ with the boundary condition $u(1,\theta)=0$ and a regularity condition at $r=0$, the right-hand side vector $\mathbf{b}$ would be identically zero (since all boundary data are zero), and the coefficient matrix $\mathbf{A}$ would be non-singular. The linear system $\mathbf{A}\mathbf{u}=\mathbf{0}$ then has only the trivial solution $\mathbf{u}=\mathbf{0}$, which is exactly the analytical result obtained above.

\begin{resultbox}
For $0\le r\le1$, the only bounded harmonic function satisfying $u(1,\theta)=0$ is
\[u(r,\theta)=0.
\]
The exterior-problem form $(r-1/r)\sin\theta$ is not valid inside the cylinder because it is unbounded at $r=0$.
\end{resultbox}
